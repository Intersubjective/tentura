Симулятор закрытия эпизода

Расчёт — §4 плана episode-closure-implementation-plan.md rev 19. Автор распределяет α_A пула помощников между «Выполнено» и «Не могу судить» (неотвеченное = «Не могу судить»; минимум 5%). Остальное помощники сдвигают одной кнопкой «Поддержать» у каждого коллеги: поддержанные получают добавку, её отдают отжатые; поддержать всех = молчание, интерфейс такого не собирает (самая ранняя отжимается сама). Вес голоса наполовину равный, наполовину по доле от автора (β). Учитывается только версия «Готово». Голосуют активные при открытии оценки, кроме исключённых автором. Итог — относительно молчания коллег. Закладка 🔖 — приватное личное ребро. Поток роутинга не моделируется.

Параметры

При двух помощниках автор распределяет 100%, при одном — весь пул одному, если он в распределении автора.
